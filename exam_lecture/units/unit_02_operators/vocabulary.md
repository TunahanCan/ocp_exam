# Unit 02 Vocabulary · Operators

Bu sözlük Unit 02 Exam Essentials ve Review Questions bağlamından seçilmiştir.
Her terimi numeric promotion, casting veya expression evaluation içindeki gerçek
anlamıyla çalış.

## A–E

### accompanied · adjective / past participle

- **Türkçe:** eşlik edilen, birlikte bulunan
- **Teknik bağlam:** Bir unary operator'ın numeric literal ile birlikte
  kullanılmasını anlatır.
- **Example:** A number is positive unless accompanied by a minus sign.
- **Çeviri:** Bir sayı, minus sign eşlik etmedikçe pozitiftir.
- **Word family:** accompany (v.), accompaniment (n.)

### apply · verb

- **Türkçe:** uygulamak
- **Teknik bağlam:** Bir rule, cast veya promotion'ın expression'a uygulanması.
- **Example:** Numeric promotion is automatically applied.
- **Çeviri:** Numeric promotion otomatik olarak uygulanır.
- **Word family:** application (n.), applicable (adj.); **synonym:** use

### assign · verb

- **Türkçe:** atamak
- **Teknik bağlam:** Bir variable'a yeni value vermek.
- **Example:** The expression assigns `false` to the variable.
- **Çeviri:** Expression variable'a `false` değerini atar.
- **Word family:** assignment (n.), assigned (adj.)

### associativity · noun

- **Türkçe:** birleşme yönü
- **Teknik bağlam:** Aynı precedence seviyesindeki operator'ların nasıl
  gruplanacağını belirler.
- **Example:** Assignment operators have right-to-left associativity.
- **Çeviri:** Assignment operator'ları sağdan sola birleşir.
- **Related:** precedence, grouping

### cast · noun / verb

- **Türkçe:** tür dönüşümü; dönüştürmek
- **Teknik bağlam:** Bir value'yu explicit olarak başka bir compatible type gibi
  ele almak.
- **Example:** Cast the result to `int` before the assignment.
- **Çeviri:** Assignment'tan önce sonucu `int`e cast et.
- **Related:** conversion, narrowing, widening

### complement · noun / verb

- **Türkçe:** tümleyen; bitleri tersine çevirmek
- **Teknik bağlam:** `~` operator'ının integer bit'lerini tersine çevirmesi.
- **Example:** The complement of `8` is `-9`.
- **Çeviri:** `8`in bitwise complement sonucu `-9`dur.
- **Related:** negation; **formula:** `~x == -x - 1`

### condensed · adjective

- **Türkçe:** kısaltılmış, yoğunlaştırılmış
- **Teknik bağlam:** Ternary expression'ın `if/else` yapısının kısa biçimi
  olmasını anlatır.
- **Example:** A ternary expression is a condensed form of `if/else`.
- **Çeviri:** Ternary expression, `if/else` yapısının kısaltılmış biçimidir.
- **Word family:** condense (v.), condensation (n.); **synonym:** compact

### determine · verb

- **Türkçe:** belirlemek, saptamak
- **Teknik bağlam:** Compiler'ın result type'ını veya expression sonucunu
  belirlemesi.
- **Example:** The compiler determines the resulting data type.
- **Çeviri:** Compiler ortaya çıkan data type'ı belirler.
- **Word family:** determination (n.), determined (adj.)

### distinction · noun

- **Türkçe:** ayrım, fark
- **Teknik bağlam:** Prefix ve postfix operator davranışları arasındaki fark.
- **Example:** The example illustrates the distinction between prefix and postfix.
- **Çeviri:** Örnek prefix ile postfix arasındaki ayrımı gösterir.
- **Word family:** distinct (adj.), distinguish (v.); **synonym:** difference

### evaluate · verb

- **Türkçe:** değerlendirmek, hesaplamak
- **Teknik bağlam:** Expression'ın operand ve operator'larını çalıştırıp value
  üretmek.
- **Example:** Java evaluates the left operand first.
- **Çeviri:** Java önce sol operand'ı değerlendirir.
- **Word family:** evaluation (n.); **synonym:** compute

## I–P

### identical · adjective

- **Türkçe:** özdeş, aynı
- **Teknik bağlam:** Logical ve conditional operator'ların truth result'larının
  aynı olabildiğini anlatır.
- **Example:** The operators are nearly identical except for short-circuiting.
- **Çeviri:** Operator'lar short-circuit dışında neredeyse aynıdır.
- **Word family:** identity (n.), identically (adv.); **antonym:** different

### increase · verb / noun

- **Türkçe:** artırmak; artış
- **Teknik bağlam:** Increment operator'ın variable value'sunu bir artırması.
- **Example:** Post-increment increases the variable after producing its value.
- **Çeviri:** Post-increment, değerini ürettikten sonra variable'ı artırır.
- **Word family:** increasing (adj.); **antonym:** decrease

### independently · adverb

- **Türkçe:** birbirinden bağımsız olarak
- **Teknik bağlam:** Her değişikliğin diğer değişiklikler uygulanmadan denenmesi.
- **Example:** Apply each change independently.
- **Çeviri:** Her değişikliği birbirinden bağımsız olarak uygula.
- **Word family:** independent (adj.), independence (n.)

### inequality · noun

- **Türkçe:** eşitsizlik
- **Teknik bağlam:** `!=` operator'ı ile iki value'nun eşit olmadığının sınanması.
- **Example:** The inequality operator can compare compatible references.
- **Çeviri:** Inequality operator uyumlu reference'ları karşılaştırabilir.
- **Antonym:** equality

### interchangeably · adverb

- **Türkçe:** birbirinin yerine geçecek şekilde
- **Teknik bağlam:** İki value'nun aynı anlam ve type kurallarıyla kullanılması.
- **Example:** Java does not use `0` and `false` interchangeably.
- **Çeviri:** Java `0` ve `false` değerlerini birbirinin yerine kullanmaz.
- **Word family:** interchangeable (adj.), interchange (n./v.)

### narrowing · noun / adjective

- **Türkçe:** daraltma, daha dar type'a dönüşüm
- **Teknik bağlam:** Büyük numeric type'tan küçük type'a explicit veya implicit cast.
- **Example:** Plain assignment requires a cast for runtime narrowing.
- **Çeviri:** Normal assignment runtime narrowing için cast gerektirir.
- **Antonym:** widening

### notable · adjective

- **Türkçe:** dikkate değer, önemli
- **Teknik bağlam:** Ternary operator'ın üç operand alan tek operator oluşunu
  vurgular.
- **Example:** The ternary operator is notable because it takes three operands.
- **Çeviri:** Ternary operator üç operand aldığı için dikkate değerdir.
- **Word family:** note (v./n.), notably (adv.); **synonym:** remarkable

### operand · noun

- **Türkçe:** işlenen
- **Teknik bağlam:** Bir operator'ın üzerinde işlem yaptığı value veya expression.
- **Example:** The ternary operator takes three operands.
- **Çeviri:** Ternary operator üç operand alır.
- **Related:** operator, expression

### overflow · noun / verb

- **Türkçe:** taşma
- **Teknik bağlam:** Integral sonucun type aralığını aşarak wraparound yapması.
- **Example:** Integer overflow does not throw an exception.
- **Çeviri:** Integer overflow exception fırlatmaz.
- **Related:** range, wraparound

### override · verb

- **Türkçe:** geçersiz kılmak, önüne geçmek
- **Teknik bağlam:** Parentheses'in normal precedence sırasını değiştirmesi.
- **Example:** Parentheses override operator precedence.
- **Çeviri:** Parentheses operator precedence'ını geçersiz kılar.
- **Word family:** overriding (adj.)

### postpone · verb

- **Türkçe:** ertelemek
- **Teknik bağlam:** Bir konunun sonraki section'da ele alınacağını belirtir.
- **Example:** The chapter postpones casting until the assignment section.
- **Çeviri:** Bölüm casting konusunu assignment bölümüne kadar erteler.
- **Word family:** postponement (n.); **synonym:** defer

### precedence · noun

- **Türkçe:** öncelik
- **Teknik bağlam:** Operator'ların hangi sırada evaluate edileceğini belirleyen
  kural.
- **Example:** Multiplication has higher precedence than addition.
- **Çeviri:** Multiplication, addition'dan daha yüksek precedence'a sahiptir.
- **Related:** priority, evaluation order

### promotion · noun

- **Türkçe:** daha geniş sayısal türe yükseltme
- **Teknik bağlam:** Numeric operand'ın işlem öncesinde daha geniş type'a otomatik
  dönüştürülmesi.
- **Example:** Binary numeric promotion converts both bytes to `int`.
- **Çeviri:** Binary numeric promotion iki byte değerini `int`e dönüştürür.
- **Word family:** promote (v.), promoted (adj.)

## R–W

### remainder · noun

- **Türkçe:** kalan
- **Teknik bağlam:** `%` operator'ının division sonrasında ürettiği kalan.
- **Example:** The remainder of `8 / 3` is `2`.
- **Çeviri:** `8 / 3` işleminin kalanı `2`dir.
- **Related:** modulus, division

### respectively · adverb

- **Türkçe:** sırasıyla
- **Teknik bağlam:** Birden çok operator veya result'ı aynı sıradaki
  açıklamalarla eşleştirir.
- **Example:** The final values are `9.0` and `3`, respectively.
- **Çeviri:** Son değerler sırasıyla `9.0` ve `3`tür.
- **Related:** in that order

### resulting · adjective

- **Türkçe:** ortaya çıkan, sonuçta oluşan
- **Teknik bağlam:** Bir operation sonrasında belirlenen data type veya value.
- **Example:** The compiler determines the resulting data type.
- **Çeviri:** Compiler ortaya çıkan data type'ı belirler.
- **Word family:** result (n./v.), resultant (adj.)

### short-circuit · adjective / verb

- **Türkçe:** kısa devreli değerlendirme
- **Teknik bağlam:** `&&` veya `||` sağ operand'ının gereksizse atlanması.
- **Example:** The `&&` operator short-circuits when the left side is false.
- **Çeviri:** Sol taraf false olduğunda `&&` operator'ı short-circuit yapar.
- **Related:** conditional operator

### side effect · noun phrase

- **Türkçe:** yan etki
- **Teknik bağlam:** İfade değeri dışında değişken veya program durumunda oluşan değişiklik.
- **Example:** Short-circuit evaluation can skip a side effect.
- **Çeviri:** Kısa devreli değerlendirme bir yan etkinin gerçekleşmesini atlayabilir.
- **Word family / karşılaştırma:** effect (n.); side-effect-free (adj.)
- **Kaynak bağlam:** [İlgili ana not](bilingual_notes.md#checking-for-unperformed-side-effects).

### surrounding · adjective

- **Türkçe:** çevreleyen
- **Teknik bağlam:** Bir unary expression'ın dışında kalan binary veya ternary
  operation'ları niteler.
- **Example:** Unary operators run before surrounding binary operators.
- **Çeviri:** Unary operator'lar çevreleyen binary operator'lardan önce çalışır.
- **Word family:** surround (v.), surroundings (n.)

### unwieldy · adjective

- **Türkçe:** kullanışsız, yönetilmesi güç
- **Teknik bağlam:** Çok sayıda iç içe kontrolün kodu zor yönetilir hâle
  getirmesini anlatır.
- **Example:** Repeating the same check makes the code unwieldy.
- **Çeviri:** Aynı kontrolü tekrarlamak kodu yönetilmesi güç hâle getirir.
- **Antonym:** manageable

### vice versa · adverbial phrase

- **Türkçe:** bunun tersi de geçerli olmak üzere
- **Teknik bağlam:** `!` operator'ının `true`yu `false`a ve tersini dönüştürmesi.
- **Example:** Logical complement changes `true` to `false`, and vice versa.
- **Çeviri:** Logical complement `true`yu `false`a çevirir; bunun tersi de
  geçerlidir.
- **Related:** conversely

### wary · adjective

- **Türkçe:** dikkatli, tetikte
- **Teknik bağlam:** Short-circuit veya side effect içeren sınav tuzaklarına
  karşı dikkatli olmayı anlatır.
- **Example:** Be wary of an unperformed side effect.
- **Çeviri:** Gerçekleşmeyen side effect'e karşı dikkatli ol.
- **Related:** beware (v.); **synonym:** cautious

### whenever · conjunction

- **Türkçe:** her ne zaman, -dığında
- **Teknik bağlam:** Farklı type'lar karıştırıldığında her seferinde geçerli olan
  genel rule'u başlatır.
- **Example:** Promotion occurs whenever smaller numeric operands are combined.
- **Çeviri:** Küçük numeric operand'lar birleştirildiğinde promotion gerçekleşir.
- **Related:** when, every time

## Önce anlam farkını geri çağır

Her oturumda en fazla beş kart seç. Türkçe anlamı kapatıp örneği sesli çevir;
sonra İngilizce terimi kapatıp Türkçeden geri çağır. **0:** hatırlamadım,
**1:** ipucuyla, **2:** örnek kurarak hatırladım biçiminde işaretle. 0/1 alan
kartları ertesi gün, 2 alanları 3/7/14 gün rotasında yeniden dene. Bu puanlar
kişisel takip içindir; hazır bir sınav puanı değildir.

`precedence` gruplamayı, `evaluation` çalıştırmayı anlatır. `result` ifadenin ürettiği değer; `side effect` değişken durumundaki ek değişikliktir. `x++` örneğinde ikisini ayrı söyle.

**Kontrol:** Bu ayrımlardan birini İngilizce iki cümleyle açıkla; yalnız Türkçe karşılığı söylemekle yetinme.

## Cevap anahtarı

1. Precedence işlemlerin nasıl gruplandığını; promotion sayısal tür dönüşümünü belirler. Operand değerlendirme sırası ayrıca izlenir.
2. Örnek: *Java evaluates each operand to determine the resulting value.*
3. `decrease`
4. *Parentheses override the normal evaluation order.*
